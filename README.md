# 📡 DXCaster

### DX spotting, propagation analysis and station control

DXCaster brings amateur radio monitoring and station tools together in one dashboard. Follow DX activity, investigate propagation conditions and point your antenna towards your next contact.

## 🌍 DX monitoring

- Live DX Cluster spots with filtering.
- Station distances and geographical bearings.
- BEAM controls linked to the antenna display.

## 🧭 Antenna and rotor control

- Control supported antenna rotors.
- Select a country prefix and beam towards its capital.
- View Short Path and Long Path bearings and distances.
- Monitor wind conditions and view compatible antenna cameras.

## 📊 Propagation and reception

- HF, 6m and 2m propagation tools.
- PSK Reporter polar reception maps and density displays.
- Compare predicted conditions with reported reception.
- Investigate VHF paths using terrain information.

## 🎛️ Radio integration and plugins

- CAT integration with supported transceivers.
- Automatic band selection from CAT or manual selection.
- Callsign Voice Monitor for supported received-audio sources.
- Optional Geochron integration and other plugin tools.

Available functions depend on your equipment and configuration.

## ⬇️ Download

Go to **Releases** in this repository and download the installer ZIP from the latest release.

1. Extract all files from the ZIP.
2. Run the DXCaster Setup `.exe`.
3. Follow the prerequisite checks.
4. Enter your callsign and email address.
5. Follow the activation instructions.
6. Complete installation and launch DXCaster using its shortcut.

**Existing users:** close your current DXCaster and install into a separate, empty folder while testing a new release.

## 💻 Requirements

- 64-bit Windows.
- PHP 8.5 or newer.
- Hamlib.
- Internet access for online feeds and services.

The installer includes the compiled Python runtime. A separate Python installation is not required to run DXCaster.

Optional features may require FFmpeg, voice-recognition models, device drivers or additional hardware.

## 🔑 Activation

DXCaster requires an activation code linked to your installation details.

Use the installer to generate your request and follow its instructions to obtain a code. Changing your computer or installation identity may require reactivation.
